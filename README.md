### Hi, I’m Tianding 👋

Computer Science **M.Sc. student at the Technical University of Munich**. I work on LLM applications, software systems, and robot learning—turning ideas into implementations I can test, inspect, and improve.

- **Research:** visual event triggers and asynchronous inference for vision-language-action policies.
- **Building:** conversational recommendation systems and practical AI applications.
- **Exploring:** agents, retrieval-augmented generation, and multimodal AI.
- **Languages:** English · Mandarin · German.

### Selected work

| Project | What I worked on | Explore |
| :--- | :--- | :--- |
